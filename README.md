
##  Task 1: Student Grade Tracker

###  Overview
The **Student Grade Tracker** is a simple Java console program that allows users to:
- Enter multiple student names and marks.
- Calculate and display:
  - **Average score** of the class.
  - **Highest** and **lowest** scoring students.
It helps in understanding array handling, loops, conditional logic, and basic statistics.
---
###  Features
- Input total number of students dynamically.
- Record each student’s name and marks.
- Compute:
  - Average marks
  - Highest marks and corresponding student
  - Lowest marks and corresponding student
- Display results in a clean, formatted output.
---
###  Core Concepts Used
- Arrays (`String[]`, `Integer[]`)
- Conditional statements (`if`, `else`)
- Loops (`for`)
- Input handling with `Scanner`
- Basic arithmetic and logic

##  Task 2: Hotel Reservation System

###  Overview
The **Hotel Reservation System** simulates a basic room booking platform where users can:
- Search available rooms by type.
- Book or cancel room reservations.
- View all existing bookings.
This system demonstrates practical use of **Object-Oriented Programming (OOP)** principles like classes, objects, encapsulation, and collections.
---
###  Features
- Predefined room types: *Standard, Deluxe, Suite*.
- Search available rooms.
- Book rooms with automatic payment simulation.
- Cancel reservations using reservation ID.
- View all reservations with customer and room details.
- Menu-driven console interface for smooth interaction.
---
###  Core OOP Concepts Used
| Concept | Usage |
|----------|--------|
| **Class & Object** | `Room`, `Reservation`, `Hotel` |
| **Encapsulation** | Room and Reservation properties managed internally |
| **ArrayList** | Store rooms and reservations dynamically |
| **Methods** | Used for booking, searching, viewing, and cancelling |
| **Control Structures** | Loops, conditionals, and menu-based input |
